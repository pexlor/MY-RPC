**遇到的问题：**
> 写日志的RAII锁问题（解决）：以RAII封装锁时，内部is_lock 变量没用原子类型，且在外部使用时显示调用了unlock()函数，线程竞争激烈时会出现释放锁问题（解锁并非原子过程）

> 连接丢失问题（解决）：Acceptor 中的acceptchannel_被设置为边沿触发模式。

> 快速反复连接问题（待解决）；目前思路：同时触发了接受和关闭
